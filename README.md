# Chart.js Bar Chart

A small bar chart built with Chart.js 3.6.0 in plain HTML, CSS and JavaScript.

## Getting started

Open `index.html` in your browser. No build step or installation is needed, Chart.js is loaded from a CDN.

## Project structure

```
.
├── index.html
├── style.css
└── script.js
```

`script.js` is split into four blocks: data structure, data, config and render.
